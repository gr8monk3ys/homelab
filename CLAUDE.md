## Run / test

```bash
./hack/validate.sh                           # what CI runs: yamllint, kubeconform, kustomize build per Flux path, no plain Secrets
k3d cluster create --config k3d/homelab.yaml # from the Windows shell, never WSL; Git Bash needs MSYS_NO_PATHCONV=1
flux get kustomizations                      # all four Ready once bootstrapped
```

Tools on this PC come from winget (`k3d.k3d`, `FluxCD.Flux`, `SecretsOPerationS.SOPS`,
`Kubernetes.kustomize`, `YannHamon.kubeconform`); in Git Bash add
`$LOCALAPPDATA/Microsoft/WinGet/Links` to `PATH`. Check `kubectl config current-context`
is `k3d-homelab` before applying anything: the default context may be Docker Desktop's.

## Where things live

- `clusters/homelab/` — three Flux Kustomizations, ordered by `dependsOn`: `infrastructure-controllers` → `infrastructure-configs` → `apps`; plus `cluster-settings` (the `${DOMAIN}`/`${TIMEZONE}` values). `flux-system/` is generated by `flux bootstrap`: never edit it by hand.
- `infrastructure/controllers/` — CRDs and operators only. Traefik is K3s's bundled chart, configured by a `HelmChartConfig` (no HelmRelease); K3s also installs the Gateway API CRDs. cert-manager and CloudNativePG are `HelmRelease`s with an `OCIRepository` chart source, pinned by tag.
- `infrastructure/configs/` — objects that need layer 1: LAN CA issuers (`selfsigned` → `homelab-ca`), the wildcard certificate and the Gateway `gateway/homelab`.
- `apps/<group>/` — `media`, `photos`, `files`. Each app gets its own directory and namespace under its group and is listed in the group's `kustomization.yaml`.
- `k3d/homelab.yaml` — the cluster. `D:\30 Media\homelab` is bound at `/mnt/bulk` on the server node.
- `docs/adr/` — decisions; 0001–0010 are superseded history, 0011 is the current shape.

## Rules

- Never commit a credential or the age private key. A Secret is a `*.sops.yaml` encrypted with `sops --encrypt --in-place` (`.sops.yaml` has the public key); CI fails on a plain `kind: Secret`.
- Pin every chart and image by version (Renovate moves them). Charts come from OCI where upstream publishes one.
- An app exposes itself with an `HTTPRoute` on `parentRefs: [{name: homelab, namespace: gateway, sectionName: https}]` and hostname `<app>.${DOMAIN}`. No Ingress objects.
- Flux substitutes `${VAR}` from `cluster-settings` in `infrastructure-configs` and `apps`: write a literal `${` as `$${`. `hack/validate.sh` fails on an unknown variable.
- Containers: `allowPrivilegeEscalation: false`, `capabilities.drop: [ALL]`, `runAsNonRoot` where the image allows.
- A single-replica Deployment on a ReadWriteOnce volume uses `strategy: Recreate`.
- Postgres only through CloudNativePG, and only where an app needs it (Immich). Everything else keeps SQLite or no database.
- Storage: app config and Postgres on `local-path` (C:, fast). Media, downloads and the photo library on `/mnt/bulk` (D:, slow RAID 5, bulk only).
- No kustomize overlays: one cluster, one environment (ADR 0003's reason still holds).
- Repo is private and Actions minutes are capped: keep CI to the one `ci.yml`, nothing scheduled.
