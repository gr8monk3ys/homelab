# CLAUDE.md

Flux GitOps homelab on one Arch Linux PC (Omarchy; RTX 3090; 3-disk RAID 5,
NTFS, for media): K3s runs natively under systemd (`host/setup.sh`), Flux pulls `main`
and applies `clusters/homelab/`. The Bash installer this replaced is on the
`archive/bash-installer` branch (ADR 0011); don't bring its patterns back
(descriptors, render placeholders, toggles, a secret table). ADRs 0012–0013 are the
current shape: native K3s, VolSync to B2, per-app Flux Kustomizations.

## Run / test

```bash
./hack/validate.sh                 # what CI runs; needs yamllint kustomize kubeconform yq flux
sudo ./host/setup.sh               # host prep + K3s (owner runs it)
./hack/cluster-secrets.sh          # once: infrastructure/secrets/cluster-secrets.sops.yaml
GITHUB_TOKEN=... ./hack/bootstrap.sh
./hack/restore.sh <ns> <app> [--test]
flux get kustomizations -A
```

Tools on this PC come from mise (`~/.local/share/mise/installs/<tool>/<ver>`);
`flux` is at `~/.local/share/mise/installs/flux2/2.10.0/flux`. The kubectl
context of the cluster is K3s's `default`.

## Where things live

- `host/` — `setup.sh` and `k3s-config.yaml`. The K3s version pin is `K3S_VERSION` in `setup.sh` (Renovate moves it).
- `clusters/homelab/` — Flux Kustomizations ordered by `dependsOn`: `cluster-secrets` → `infrastructure-controllers` → `infrastructure-configs` → `apps`; plus `cluster-settings`. `flux-system/` is generated by `flux bootstrap`: never edit it.
- `infrastructure/secrets/` — `cluster-secrets.sops.yaml`, every credential, made by `hack/cluster-secrets.sh` (the key list is in that script).
- `infrastructure/controllers/` — operators, CRDs, charts: Traefik `HelmChartConfig` (K3s bundles Traefik and the Gateway API CRDs), cert-manager, CNPG, VolSync, kube-prometheus-stack, smartctl-exporter, NVIDIA device plugin + GPU exporter.
- `infrastructure/configs/` — LAN CA issuers, wildcard cert, Gateway `gateway/homelab`, k8s-gateway DNS, Grafana route, `PrometheusRule`s, Flux → ntfy alerts.
- `apps/<group>/` — `namespace.yaml` (one namespace per group, with a default-deny-ingress NetworkPolicy), shared volumes, and `<app>/ks.yaml` + `<app>/app/`. Groups: `media`, `photos`, `files`.
- `components/volsync/` — nightly restic backup of PVC `${APP}` to B2.
- `docs/adr/` — 0011–0013 current; `superseded/` holds 0001–0010. `docs/runbooks/` — bring-up, disaster recovery.

## Rules

- Never commit a credential or the age private key. Credentials go in `cluster-secrets` (`sops edit infrastructure/secrets/cluster-secrets.sops.yaml`; add new key names to `hack/cluster-secrets.sh`) and reach manifests as `${VAR}`. A Secret manifest outside SOPS may hold only `${VAR}` values; CI enforces it.
- A new app: `apps/<group>/<app>/ks.yaml` (copy `apps/media/prowlarr/ks.yaml`), listed in the group's `kustomization.yaml`. Deployment name = `APP` = its config PVC name (the VolSync component and `hack/restore.sh` rely on it). Include the volsync component if it has state.
- Pin every chart and image by exact version; check the tag exists. Charts come from OCI where upstream publishes one. Stay on stable lines (home-operations also publishes arr prereleases; `renovate.json5` caps them).
- An app exposes itself with an `HTTPRoute` on `parentRefs: [{name: homelab, namespace: gateway, sectionName: https}]`, hostname `<name>.${DOMAIN}`. No Ingress (CI fails).
- Every app renders a NetworkPolicy allowing its ingress (from Traefik: namespace `kube-system`, label `app.kubernetes.io/name: traefik`), or its Namespace says why not (`homelab.io/no-network-policy`).
- Containers: `allowPrivilegeEscalation: false`, `capabilities.drop: [ALL]`, `runAsNonRoot` as 1000:1000 where the image allows; an exception is a pod annotation `homelab.io/security-exception: <reason>`. CI enforces the first two.
- A single-replica Deployment with a PVC uses `strategy: Recreate` (CI enforces).
- GPU workloads: `runtimeClassName: nvidia`, `limits: {nvidia.com/gpu: 1}` (time-sliced, 4 slots, no memory isolation).
- Postgres only through CloudNativePG, only where an app needs it (Immich).
- Storage: app config and Postgres on `local-path` (SSD, `/var/lib/homelab/volumes`). Media and downloads on the RAID under `${BULK_PATH}`, the Immich library on the SSD at `${PHOTOS_PATH}`, both via static hostPath PVs (ADR 0013). ntfs3 means no Unix owners (everything 1000:1000) and unreliable xattrs: nothing that needs them goes on the RAID.
- Flux substitutes `${VAR}`; write a literal `${` as `$${`. Prometheus `{{ $labels.x }}` is safe.
- No kustomize overlays: one cluster, one environment (`superseded/0003`'s reason still holds).
- Repo is private and Actions minutes are capped: keep CI to the one `ci.yml`, nothing scheduled.
